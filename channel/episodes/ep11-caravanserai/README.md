# Explorer's Ledger, part 6: Persia's Ancient Hotel Chain

- Format: vertical 9:16, about 60 s, 15 scenes
- Video: `output/explorer-part6-caravanserai.mp4`
- Free tools: HyperFrames (vector animation), Kokoro English voice (offline, via sherpa-onnx), Fredoka captions, code-generated music
- Script: `vo/lines.txt` · scenes: `scenes.js` · upload metadata: `meta-upload.json`
- Rebuild: `KOKORO_DIR=... python3 ../../explorer-kit/build.py .` then `npm run render`

## Facts to double-check
1. Shah Abbas I (r. 1588-1629) built many caravanserais; the '999' figure is a legend.
2. Spacing of roughly one day's journey (about 30-40 km) is typical but varied.
3. 'The Persian Caravanserai' (54 sites) was inscribed by UNESCO in 2023.
