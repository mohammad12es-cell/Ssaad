# موشن‌گرافیک «ثبت شرکت در ارمنستان»: سناریو و صدای Google AI Studio

پروژه: `armenia-company/` (HyperFrames + Three.js، عمودی ۱۰۸۰×۱۹۲۰، ۱۰ صحنه‌ی سه‌بعدی، پالت IRAM CO.)

سناریو از صدای ویدیوی ارسالی گرفته شده است (Whisper large-v3، `armenia-company/transcript.json`). متن ویرایش و غلط‌های تشخیص گفتار اصلاح شده است.

## متن کامل گوینده (برای کادر متن AI Studio)

> اگه توی ارمنستان اشتباه شرکت ثبت کنی، جریمه می‌شی.
> ثبت شرکت فقط انتخاب یه اسم و گرفتن برگه‌ی ثبت نیست.
> باید اول از همه بدونی چه نوع شرکتی مناسب فعالیت توئه.
> موضوع فعالیت شرکت رو چجوری ثبت کنی؟ چه اطلاعاتی رو باید توی مدارکت بذاری؟
> چه تعهدات مالیاتی و قانونی بعد از ثبت شرکت داری؟ و هزارتا سؤال دیگه.
> چون یه دونه انتخاب یا یه دونه اطلاعات اشتباه برات دردسرهای بزرگی درست می‌کنه.
> حتی توی بعضی از موارد هم جریمه‌های قانونی به همراه داره.
> از طرفی هم مسیر ثبت شرکت توی ارمنستان مشخصه، و ثبت رسمی شرکت توسط سازمان ثبت اشخاص حقوقی وزارت دادگستری انجام می‌شه.
> پس قبل از این‌که فقط دنبال ثبت سریع شرکت باشی، اول باید مشخص بشه چه شرکتی، با چه فعالیتی و چه ساختاری برای تو مناسب‌تره.
> برای مشاوره‌ی رایگان ثبت شرکت، کلمه‌ی «شرکت» رو کامنت کن.

## ساخت صدا با Google AI Studio

### راه ۱: دستی در سایت (همان کاری که برای ویدیوی قبلی کردید)
1. aistudio.google.com ← **Generate speech** ← **Single-speaker audio**.
2. مدل: بهترین مدل TTS موجود (Gemini … Pro TTS). صدا: **Charon** (همان صدای ویدیوی قبلی؛ جایگزین‌ها: Orus، Algenib).
3. در **Style instructions** این را بگذارید:
   > Read this in Persian (Farsi), Tehrani conversational accent, as a warm, confident, trustworthy male narrator for a short Instagram ad about registering a company in Armenia. Start with a serious warning tone on the first line, then clear and helpful. Medium-fast pace, natural pauses at commas and between sentences, slight energy lift on key words, friendly call to action at the end. Do not read any punctuation marks aloud.
4. متن کامل گوینده (بالا) را در کادر متن بگذارید، Run بزنید و WAV را دانلود کنید.
5. فایل را در همین گفتگو بفرستید. صحنه‌ها و زیرنویس‌ها خودکار روی آن چیده می‌شوند:
   ```bash
   cd armenia-company
   python3 build.py single voice.wav                     # برش جمله‌ها روی مکث‌های صدای جدید
   # برای زیرنویس دقیق کلمه‌به‌کلمه: Whisper روی assets/voiceover.wav، سپس
   python3 build.py single voice.wav words.json
   npx --yes hyperframes@0.9.13 render -o ../output/armenia-company.mp4
   ```

### راه ۲: خودکار با کلید API
میزبان `generativelanguage.googleapis.com` از این محیط در دسترس است و فقط کلید لازم دارد. کلید را از aistudio.google.com ← **Get API key** بگیرید. آن را در تنظیمات محیط ابری این جلسه (منوی محیط در نوار عنوان ← Edit ← Network secrets) برای همین میزبان، با هدر `x-goog-api-key`، ذخیره کنید. سپس:
```bash
cd armenia-company
python3 gen_vo.py        # هر جمله جدا با Gemini TTS (صدای Charon) ← assets/vo/s1.wav ...
python3 build.py vo
npx --yes hyperframes@0.9.13 render -o ../output/armenia-company.mp4
```

## صدای ساخته‌شده (نسخه‌ی نهایی)
- مدل `gemini-3.8-flash-tts`، صدای **Charon**، هر جمله جدا: `armenia-company/assets/vo/s1.wav` تا `s10.wav`. چیده‌شده روی هم: `assets/voiceover.wav`.
- آخر هر کلیپ یک ضربه‌ی نویز حدوداً ۰٫۱۵ ثانیه‌ای داشت که حذف شد. جمله‌ی ۹ در خروجی مدل بعد از متن صدای اضافه داشت و از انتهای جمله بریده شد.
- زیرنویس‌ها با زمان کلمه‌های Whisper روی همین صدا چیده شده‌اند: `python3 build.py vo vo_words.json`.
- موسیقی ۱۵ dB زیر صدای گوینده است و وقتی گوینده حرف می‌زند حدوداً ۶ dB پایین می‌رود.
- سهمیه‌ی رایگان هر مدل TTS، ۱۰ درخواست در روز است. برای ساخت دوباره‌ی یک جمله: `python3 gen_vo.py --only s3` (کلید با متغیر `GEMINI_API_KEY`).
