# THE LAST HUMAN — Episode 01: NO SIGNAL

A 30-second vertical (9:16) stylized-3D cyberpunk episode. Everything is procedural: the
city, characters, drone, holograms, titles and the full soundtrack are generated by code in
this folder. No stock footage, no samples, no paid APIs, no copyrighted music.

## Deliverables (`output/`)

| File | Contents |
|---|---|
| `THE_LAST_HUMAN_EP01_FA.mp4` | English dialogue + burned-in Persian subtitles |
| `THE_LAST_HUMAN_EP01_EN.mp4` | English dialogue + burned-in English subtitles |
| `THE_LAST_HUMAN_EP01_CLEAN.mp4` | Clean cinematic version, no subtitles |

### Render settings

| | |
|---|---|
| Resolution | 1080 × 1920 (9:16), square pixels |
| Frame rate | 30 fps constant, exactly 900 frames, 30.000 s |
| Video | H.264 High @ L4.2, yuv420p, CRF 18 capped at 16 Mb/s (x264 `slow`), GOP 60, BT.709 tags, `+faststart` |
| Audio | AAC-LC 192 kb/s, 48 kHz stereo, mastered to −14 LUFS integrated, −1 dBTP |
| Frames | rendered losslessly to PNG; each deliverable is encoded once from the PNGs |

`python3 tools/validate.py` checks all of the above, plus full error-free decoding and that
subtitles appear only where they should.

## Pipeline

```
src/        Three.js r170 scene code (runs in a browser)
  main.js     entry; window.renderFrame(f) renders frame f deterministically
  shots.js    timeline: shot boundaries, story beats, kinematics, crowd, drone choreography
  world.js    Neo-Eden: instanced towers + window shader, canyon facades, wet planar-reflection
              street with rain ripples, neon, holo-ads, flying traffic, rain, fog, light rig
  human.js    character builder (Kael + citizens): sculpted head, eyes/lids/brows, scar, hair
              locks, ears, neural implants, jacket details, procedural walk cycle
  drone.js    surveillance drone: iris eye shader, ducted rotors, scan cone + spot light
  eye.js      Shot 1 full-screen eye shader (cornea reflects a render of the city)
  hud.js      hologram panel + title card
  ads.js      original ad artwork (no real brands)
  post.js     bloom, ACES, grade, chromatic aberration, grain, glitch
  fonts/      Orbitron, Rajdhani, Vazirmatn (SIL OFL, licenses included)
render/     render.mjs (Playwright frame capture), subs.mjs (subtitle overlays), server.mjs
audio/      build_audio.py (all music/SFX/ambience synthesized), voice/eve_line.wav
subtitles/  EP01_FA.srt, EP01_EN.srt (source of truth for burned-in subtitles)
tools/      assemble.py (encode), validate.py, sheet.py (contact sheets)
```

### Requirements
Node 18+ with Playwright + Chromium (any headless Chromium with WebGL; software SwiftShader works),
Python 3 with numpy, FFmpeg with libx264. No GPU needed.

### Build everything
```bash
npm run frames     # 900 PNGs -> build/frames  (resumable: --skip keeps finished frames)
npm run subs       # SRT cues -> transparent PNG overlays (Chromium shapes Persian correctly)
npm run audio      # synthesized score/SFX/ambience + E.V.E. voice -> build/audio/mix.wav + stems
npm run assemble   # -> output/*.mp4 + SRT copies
npm run validate
```
Render time on a 4-core CPU with software WebGL: ~3.2 s/frame (~50 min for the episode).
Single frames: `node render/render.mjs --out build/stills --frames 0,450,800`.
Interactive preview: serve `src/` (e.g. `npx http-server src`) and open `index.html`
(arrow keys scrub ±0.5 s).

## Characters — consistency rules
- **Kael** is created once in `main.js` with fixed parameters (`seed: 7`, skin, dark-brown iris,
  messy black hair, black jacket with gunmetal/silver trims, scar above the LEFT eyebrow,
  `neural: false`). The same mesh is used in every shot — never re-parameterized.
- **Citizens** share the builder with `neural: true` (cyan implant behind both ears) and seeded
  variation in skin, coat, hair/hood and LED-rim umbrellas.
- **E.V.E.** is voice only. The drone is her eye.

## Voice — E.V.E.
`audio/voice/eve_line.wav` was generated locally with the open-source **Piper** TTS
(voice `en_GB-jenny_dioco-medium`, length-scale 1.45), then processed in `build_audio.py`
(band-limit, detuned doubler, subtle 38 Hz ring-mod, micro-stutter on "-ble", plate reverb)
to sound calm, synthetic and subtly disturbed.

**Replacing it with a real performance:** record the line (any rate, mono/stereo WAV), then
```bash
python3 audio/build_audio.py --voice path/to/take.wav            # same synthetic treatment
python3 audio/build_audio.py --voice take.wav --voice-raw         # already-processed take
python3 audio/build_audio.py --voice take.wav --voice-at 26.30    # nudge sync
npm run assemble && npm run validate
```
Dialogue window: 26.35 s → 27.95 s (subtitles use the same times). Stems are written to
`build/audio/stem_{music,ambience,sfx,voice}.wav` for re-mixing.

## Subtitles
- Persian: Vazirmatn Bold, white, soft dark shadow, centered, 90 px side margins, baseline
  ~73 % of frame height (clear of mobile app UI), `dir="rtl"` with full HarfBuzz shaping.
  FA track also translates the on-screen hologram text and the title.
- Edit `subtitles/*.srt`, then `npm run subs && npm run assemble`.
